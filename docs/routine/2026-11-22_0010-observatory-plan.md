# 2026-11-22 00:10 — 观察台总体方案（仅文档）

## 用户确认的方向
1. 产品定位：只用自然语言，云端模型（官方 CLI）构建项目，本地小模型中转与做基础文件/系统操作，用户只看可视化界面；现有工具保留但降为“高级”。
2. 一次性授权令牌（CLI、目录、token 预算、需批准的操作），范围内自动、超出才问。
3. **网络策略改为按进程限制**：不必整机离线，只保证本地模型没有网络请求能力；CLI 可在同一虚拟机内以独立用户、限域名联网运行（不再需要单独构建虚拟机）。
4. 必须省 token；小模型框架要仔细设计并省资源。
