# 2026-11-20 20:14 — 项目文件树异步请求与变更筛选可靠性修复

## 改动摘要
- `ProjectExplorer.tsx`: 为项目概览、文件 Diff 和阶段检查点分别使用请求序号，忽略已被后续选择覆盖的异步响应；切换任务、阶段时显式清除过时的文件详情和报告。

- `projectEvidence.test.mjs`: 新增对保留变更父级目录和折叠行为的回归测试。
