# 2026-11-23 13:54 — 前端审计：假按钮、渲染异常、审美

## 背景
用户："审计一下前端代码和渲染一下，看有没有假按钮和渲染失常，同时检查审美"。

## 怎么做的
- **用真实后端，不用夹具**：`make_server` + 临时工作区（几份示例文件），服务真正构建出来的 `workbench/dist`，所以看到的就是镜像里用户会看到的。
- Playwright（Chromium）逐个打开 13 个视图，三种设置：深色 1440×900、浅色 1440×900、深色 1024×700。每个视图检查：
  - 控制台错误、页面异常、HTTP ≥ 400；
  - 整页横向滚动、被截断或溢出编辑区的文字；
  - **静态假按钮**：可见的 button/tab/option/链接上，读 React 实际绑定的属性，看有没有点击处理函数；
  - 没有可读名字的按钮，禁用了却不说明原因的按钮；
  - 对比度（WCAG：正文 4.5:1，大字 3:1），图标是否显示为空白，中文界面里有没有整句英文。
- **动态点击**：把每个视图里每个可用按钮都点一遍（每次先重新打开视图），点完界面没变化、也没有发请求的，记为"没有效果"。
  - 关机/重启接口在浏览器层被拦截，确认对话框里的按钮不点。

## 发现并修复的问题

| # | 问题 | 严重度 | 原因 → 修复 |
|---|---|---|---|
| 1 | **整个界面的图标全部不显示**（活动栏空白、侧栏、状态栏、标签页都没有图标） | 高：已发布的 0.3.0 镜像里就是这样 | 图标字体是 `codicon.ttf`，而工作台服务只允许 `.woff2` 等后缀，`.ttf` 返回 404。之前的截图用的是模拟服务器，没有暴露出来 → `ASSETS` 加上 `.ttf`/`.woff`，并加测试 |
| 2 | 打开的标签多了以后，**整个窗口横向撑宽**，标题栏和状态栏一起被推出屏幕 | 中 | 最外层 grid 的列没有上限，标签栏的最小宽度把它撑开 → `grid-template-columns:minmax(0,1fr)`，`.main{min-width:0}` |
| 3 | AI 文件管理里，**根目录下的文件缩进到了中间** | 中 | `.aiws-os-file-list button span{flex:1}` 把占位空白也拉成了半行宽 → 占位改成单独的 `aiws-os-tree-pad`（固定 14px） |

| 5 | 模型开关页标题还写"**本地 2B 智能助手**"，状态显示英文 `DISABLED` | 中 | → "本地模型（Qwen3.5-9B）"，状态改成中文"在线 / 已启用，服务未就绪 / 未启用" |

| 7 | "新对话"在已经是空对话时**点了没有任何效果** | 低 | 动态点击发现的唯一一个 → 这种情况下禁用，并提示"已经是新对话" |

| 12 | 内核状态显示英文 `unavailable`；一个只有图标的刷新按钮没有可读名字；浅色主题下警告徽章对比度 4.36:1 | 低 | → "无法读取"；加 `aria-label`/`title`；浅色主题下警告徽章用白字 |

## 修复后结果
- 三种设置下，13 个视图全部：没有页面错误、没有整页横向滚动、没有被截断的文字、没有空白图标、没有整句英文、没有低对比度文字、没有无名按钮。
- **静态检查**：所有可见按钮都绑定了处理函数（每个视图 22–48 个）。
- **动态点击**：31 个可用按钮全部有效果。
- 只剩两种 HTTP 错误，都是环境决定、界面表现正确：
  - 变更页 400：示例工作区不是 Git 项目，现在显示成说明。
  - 服务与内核页 403：这个沙箱以 root 运行，服务按设计拒绝；真机里不会出现。

## 新增测试
- `os/verify/test_workbench_routes.py::StaticAssets`：UI 构建产物和 codicons CSS 引用到的每种文件后缀都必须在 `ASSETS` 里。**变异检验**：去掉 `.ttf` → 失败。
- `workbench/tests/icons.test.mjs`：源码里写死的每个图标名都必须存在于 codicon 字体。**变异检验**：改回 `power` → 失败。
